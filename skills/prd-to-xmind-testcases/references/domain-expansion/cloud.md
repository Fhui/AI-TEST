- 云端成片
- 云端加急

## Workflow Patterns

- 创建流水 -> 进入云端大队列 -> 修图师接单 -> 完成修图 -> 提交流水(非绿色通道) -> 云端审核(发放收益和海草经验) -> 完成云端修图
- 创建流水 -> 进入云端大队列 -> 修图师接单 -> 完成修图 -> 提交流水(绿色通道, 发放收益和海草经验) -> 完成云端修图
- 创建流水 -> 进入云端指派队列 -> 指派修图师接单 -> 完成修图 -> 提交流水(非绿色通道) -> 云端审核(发放收益和海草经验) -> 完成云端修图
- 创建流水 -> 进入云端指派队列 -> 云端加急 -> 进入云端大队列 -> 修图师接单 -> 完成修图 -> 提交流水(非绿色通道) -> 云端审核(发放收益和海草经验) -> 完成云端修图
- 云端审核人接单 -> 接到待审核状态流水 -> 审核通过(发放修图师修图收益和海草经验) -> 完成云端修图
- 其他系统退单 -> 创建R流水 -> 修图师接单 -> 进入审核队列 -> 审核人接单 -> 选择审核结果 -> 完成审核(扣减修图师收益和海草经验) -> 完成云端修图
- 修图师流水被其他系统退回并且审核为质量问题 -> 修图师发起申述 -> 进入申述列表 -> leader申述一审通过 -> 进入二审列表 -> 质量管理员二审通过 -> 修图师收益和海草经验恢复 -> 完成云端修图
- 创建流水(wait_retouch) -> 修图师接单(retouching) -> 完成修图(wait_review) -> 审核中(reviewing) -> 完成审核(finish)

## Expansion Dimensions

- 流水：C流水,R流水
- 退单审核：质量修改, 非质量修改, 质量重修, 非质量重修
- 收益: 修图收益, 海草收益
- 收益公式:
  - 质量修改:
    - C流水: 原照片收益*0.5, 海草收益*0.5
    - R流水: 原照片收益*0.5, 海草收益*0.5
  - 质量重修:
    - C流水: 原照片收益*0, 海草收益*0
    - R流水: 原照片收益*1, 海草收益*1
  - 非质量修改:
    - C流水: 原照片收益*1, 海草收益*1
    - R流水: 原照片收益*0.5, 海草收益*0.5
  - 非质量重修:
    - C流水: 原照片收益*1, 海草收益*1
    - R流水: 原照片收益*1, 海草收益*1
