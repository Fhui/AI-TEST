# WatchPic Domain Profile

适用于：

- 在线看片
- 看片师工作台
- 取片服务
- 自助裁剪
- 图片处理与多版本结果展示
- 看片历史记录
- 在线看片小程序
- 看片师裁剪

## System Terminology

- 看片师
- 看片单
- 取片单
- 满意片
- 裁剪结果
- 排版照
- 尺寸类别
- 多版本结果
- 看片队列

## Workflow Patterns

- 发送看片通知 -> 选择看片方式 -> 选择在线看片 -> 满意照片 -> 选择裁剪方式 -> 自助裁剪 -> 完成裁剪 -> 确认取片 -> 创建取片单 -> 完成取片
- 发送看片通知 -> 选择看片方式 -> 选择在线看片 -> 发送建议 -> 看片师接单 -> 修改照片 -> 满意照片 -> 全部满意照片 -> 选择裁剪方式 -> 自助裁剪 -> 完成裁剪 -> 确认取片 -> 创建取片单 -> 完成取片
- 发送看片通知 -> 选择看片方式 -> 选择在线看片 -> 满意照片 -> 全部满意照片 -> 选择裁剪方式 -> 看片师裁剪 -> 看片师接单 -> 看片师完成裁剪 -> 确认取片 -> 创建取片单 -> 完成取片
- 发送看片通知 -> 选择看片方式 -> 选择门店看片 -> 预约门店看片 -> 到店签到门店看片 -> 门店看片师接单 -> 满意照片 -> 完成看片

## Expansion Dimensions

- 产品:
  - 分类: 支持在线看片产品可以选择在线看片, 否则只能门店看片
  - 裁剪: 产品支持可裁剪, 不可裁剪产品, 可贴图, 不可贴图产品
    - 尺寸类别: 一个产品支持多种类别, 分别为:登记照,证件照,签证照
      - 尺寸信息: 一个尺寸类别下有多个尺寸信息
        - 照片版本: 一个尺寸类别下有多个照片版本, 一般支持:"高清裁剪版", "办证报考版", "高清版"
          - 每个照片版本可以配置是否支持版本照
- 队列
  - 不同类型的订单进入不同的队列
  - 队列类型如下
    - AI私有队列
    - AI共有队列
    - 门店私有队列
    - 门店共有队列
    - 云端私有队列
    - 云端共有队列
    - 门店结对队列
  - 门店修看类型队列流转
    - 门店私有队列
    - 门店共有队列
    - 云端共有队列
    - 门店结对队列
  - 云端修看类型队列流转
    - 云端私有队列
    - 门店私有队列
    - 门店共有队列
    - 云端共有队列
  - AI直出类型队列流转
    - AI私有队列
    - AI共有队列
    - 门店私有队列
    - 门店共有队列
    - 云端共有队列
  本 profile 不包含具体版本测试用例。
