# Context Consumption

## Goal

消费 `test-knowledge-retrieval` 产出的上下文包，将历史资料压缩为当前 PRD 分析可用的上下文。

## Context Injection Semantics

命中历史知识库后，历史 PRD、历史测试用例、历史缺陷、接口文档、上下游说明必须作为当前 PRD 的分析上下文进入后续 AI 建模链路。

历史资料是上下文，不是当前 PRD 本身。

当前 PRD 的新增、变更、删除语义优先于历史资料。

## Must Extract

- 历史 PRD 关联点
- 历史测试用例复用点
- 历史缺陷高风险点
- 上下游系统影响范围
- 本次变更影响范围
- 需要回归的旧流程
- 需要新增的测试点
- 规则有效性判断
- 影响范围分析
- 冲突点
- open_questions

## Rule Validity

历史规则必须区分：

- 本次仍然有效
- 本次被修改
- 本次被废弃
- 与当前 PRD 冲突，需确认

## Impact Analysis

必须覆盖：

- 当前模块影响
- 上游输入影响
- 下游输出影响
- 数据结构影响
- 接口兼容性影响
- 状态流转影响
- 权限影响
- 通知 / 异步任务影响
- 历史用例回归影响

## Forbidden

- 把全部历史测试用例转成回归测试点
- 忽略当前 PRD 与历史资料冲突
- 只生成新增功能用例
- 只分析当前模块，不分析上下游
