# Photo Processing Expansion Sample

示例只用于 few-shot，不是主规则。

## Matrix

```text
输入类型 x 处理方式 x 配置开关 x 结果形态 x 版本形态
```

## Case Groups

- CG-001 单输入资源在默认配置下处理成功并生成单结果
- CG-002 多输入资源在默认配置下处理成功并生成多结果
- CG-003 输入资源不合法时处理失败并给出错误提示
- CG-004 自动处理结果存在后，人工结果覆盖自动结果
- CG-005 多版本结果在预览入口正确展示
- CG-006 下游历史展示入口正确展示最终结果
