# 示例输出

以下示例展示目标输出形态。层级固定为 `系统 -> 版本 -> 模块 -> 用例`，每条用例都包含 `tc / ts / ti / tp`。
为避免污染规则层，示例使用通用对象、状态、行为和规则，不绑定具体业务实体。

- 系统, 资源管理系统
  - 版本, v1.0.0
    - 模块, 对象创建
      - tc: 满足规则时创建对象成功
        - ts: 使用具备操作权限的主体进入创建页面。
          - 成功进入对应页面
        - ts: 输入合法属性并提交创建行为。
          - 对象创建成功并进入已创建状态
        - ti: P0
        - tp: 主体已登录；具备创建权限；存在合法输入数据
      - tc: 缺少必填属性时创建对象失败
        - ts: 使用具备操作权限的主体进入创建页面。
          - 成功进入对应页面
        - ts: 缺少必填属性并提交创建行为。
          - 系统提示规则不满足且不创建对象
        - ti: P1
        - tp: 主体已登录；具备创建权限
      - tc: 重复唯一标识时创建对象失败
        - ts: 使用具备操作权限的主体进入创建页面。
          - 成功进入对应页面
        - ts: 输入重复唯一标识并提交创建行为。
          - 系统提示唯一性冲突且不创建对象
        - ti: P1
        - tp: 已存在具有相同唯一标识的对象
    - 模块, 状态变更
      - tc: 满足触发条件时对象状态成功流转
        - ts: 打开处于初始状态的目标对象。
          - 成功展示对象详情
        - ts: 执行触发状态变化的行为。
          - 对象状态流转到目标状态
        - ti: P0
        - tp: 目标对象存在；当前状态允许触发该行为
      - tc: 当前状态不允许时禁止执行状态变更
        - ts: 打开处于受限状态的目标对象。
          - 成功展示对象详情
        - ts: 执行不被当前状态允许的行为。
          - 系统拒绝执行并保持原状态不变
        - ti: P1
        - tp: 目标对象存在；当前状态不允许该行为
      - tc: 外部依赖失败时状态变更进入失败补偿路径
        - ts: 打开目标对象并触发状态变化行为。
          - 行为被成功发起
        - ts: 模拟外部依赖返回失败。
          - 系统进入失败处理或补偿流程，并记录失败结果
        - ti: P1
        - tp: 目标对象存在；该行为依赖外部系统
      - tc: 延迟或异步处理完成后对象状态最终一致
        - ts: 触发异步状态变更行为。
          - 系统接受请求并进入处理中状态
        - ts: 等待异步任务完成。
          - 对象最终进入目标状态，且结果与任务状态一致
        - ti: P1
        - tp: 存在异步处理能力；目标对象处于可处理状态
