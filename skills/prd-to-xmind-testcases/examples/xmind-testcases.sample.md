# 示例需求V1.0

## V1.0

### 管理端

- 对象管理

  - 创建对象

    - tc: 合法数据创建对象成功

      - ts: 进入对象创建页面

        - 页面展示创建表单

      - ts: 输入合法数据并提交

        - 对象创建成功并进入目标状态

      - ti: P0

      - tp: 用户已登录并具备创建权限

- 历史回归

  - 对象管理历史主流程

    - tc: 历史对象创建主流程回归

      - ts: 按历史主流程创建对象

        - 创建成功，历史主流程不受影响

      - ti: P0

      - tp: 命中历史回归候选
