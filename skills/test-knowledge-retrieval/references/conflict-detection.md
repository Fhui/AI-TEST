# 冲突识别参考

## 需要对比的来源

将当前 PRD 与以下资料进行对比：

- 历史 PRD。
- 历史测试用例预期。
- 历史缺陷修复说明。
- 接口文档。
- 发布说明。
- shared 规则。

## 冲突信号

以下内容不一致时记录冲突：

- 状态流转。
- 角色或权限规则。
- 接口字段、枚举、必填性、错误码或兼容行为。
- 通知时机、接收人、去重或重试行为。
- 异步、回滚、幂等或并发行为。
- 上下游归属或数据契约。
- 发布门禁或迁移规则。

## 必需格式

`context-package.json` 中使用以下结构：

```json
{
  "type": "",
  "current_rule": "",
  "historical_rule": "",
  "sources": [],
  "reason": "",
  "needs_confirmation": true
}
```

除非当前 PRD 明确解决冲突，否则禁止自行裁决哪一方正确。若当前 PRD 已明确取舍，在 `retrieval_summary` 中说明解决结果即可，不必写入冲突。
